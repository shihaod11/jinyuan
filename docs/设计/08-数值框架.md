## 数值框架（初稿，等模拟器跑完再调）

**设计目标：配装中等的玩家，从 1 级到 60 级杀一只普通怪都在 0.5–1 秒；终局变慢，要靠 BD 把它压回去。** 下面的公式和表是我用脚本算出来的第一版，它们的作用是让各系统“量级对得上”，精确数字以后由模拟器调。

### 成长公式（L = 等级，怪物等级最高 85）

```latex
\text{普通怪生命}(L) = 18 \times 1.08^{L-1} \times (1 + 0.05(L-1))
```

```latex
\text{普通怪单次伤害}(L) = 6 \times 1.05^{L-1} \times (1 + 0.025(L-1))
```

```latex
\text{升级所需经验}(L) = (40L^{2.6} + 120L) \times (1 + 0.12\max(0, L-60)) \times (1 + 0.25\max(0, L-85))
```

怪物生命每级涨约 8%，玩家的伤害靠六个来源相乘追上：武器/法术基础、宝石等级、“提高”类加成、辅助宝石的“更多”、暴击、攻速。哪个来源缺了，玩家就会感觉“打不动了”，这就是换装和改 BD 的动力。

> 【图：击杀时间曲线】中等配装击杀同级普通怪：1 级 1.06 秒，10 级 0.8，20 级 0.62，30 级 0.54，40–60 级约 0.64，70 级 0.83，80 级 1.17，85 级起 1.7 秒（怪物等级封顶）。目标区间 0.5–1 秒。计算脚本：docs/数值初稿计算.py

85 级以后怪物不再变强，但“中等配装”的伤害也到顶了，剩下的差距由传奇、升华、符文之语补上，这就是终局“刷”的理由。
