## 数据格式样例

**下面 6 段就是“框架”落地后的样子：以后加内容，就是照着写这种表。** 字段名用英文（代码好处理），显示文字用中文。

### 修饰器（所有系统的通用零件）

```json
{ "stat": "damage", "kind": "increased", "value": 30,
  "tagsAll": ["fire"], "condition": null, "source": "affix:fire_dmg_t4" }
```

### 词缀

```json
{ "id": "life_flat", "group": "life", "type": "prefix",
  "slots": ["helmet", "body", "gloves", "boots", "belt", "ring", "amulet"],
  "text": "+{0} 最大生命",
  "tiers": [
    { "tier": 7, "ilvl": 1,  "min": 5,   "max": 9,   "weight": 1000 },
    { "tier": 1, "ilvl": 84, "min": 125, "max": 139, "weight": 250 }
  ],
  "mods": [{ "stat": "life", "kind": "flat", "value": "{0}" }] }
```

### 技能宝石

```json
{ "id": "ember_bolt", "name": "烬火球", "tags": ["spell", "projectile", "area", "fire"],
  "attribute": "int", "castTime": 0.7, "cost": { "mana": 8 },
  "delivery": { "type": "projectile", "count": 1, "speed": 520, "lifetime": 1.2,
                "onHit": { "type": "area", "radius": 1.6 } },
  "payload": { "damage": { "fire": ["base", 0.9, 1.1] }, "igniteChance": 20 },
  "levels": { "base": [9, 12, 16, 21, 27], "costGrowth": 1.08, "reqLevel": [1, 4, 7, 10, 13] } }
```

### 辅助宝石

```json
{ "id": "multi_proj", "name": "多重投射", "requiresTags": ["projectile"],
  "costMult": 1.3,
  "mods": [
    { "stat": "projectile_count", "kind": "flat", "value": 2 },
    { "stat": "damage", "kind": "more", "value": -30 }
  ] }
```

### 传奇装备（特效 = 触发器）

```json
{ "id": "ember_oath", "name": "余烬之誓", "base": "sword_t2",
  "mods": [
    { "stat": "damage", "kind": "increased", "value": [60, 80], "tagsAll": ["physical"] },
    { "stat": "ignite_chance", "kind": "flat", "value": 25 }
  ],
  "triggers": [
    { "on": "kill", "if": { "targetHas": "ignite" }, "chance": 100, "cooldown": 0,
      "do": { "action": "spread_ailment", "ailment": "ignite", "radius": 3 } }
  ],
  "flavor": "火会灭，誓言不会。" }
```

### 天赋节点

```json
{ "id": "n_forge_heart", "type": "notable", "name": "熔炉之心",
  "pos": [412, -88], "links": ["n_fire_s3", "n_fire_s4"],
  "mods": [
    { "stat": "damage", "kind": "increased", "value": 25, "tagsAll": ["fire"] },
    { "stat": "ignite_duration", "kind": "increased", "value": 20 }
  ] }
```

每种表都配一个检查脚本（tools/validate）：字段拼错、标签不存在、档位数值不递增，都会在启动游戏前报出来。
