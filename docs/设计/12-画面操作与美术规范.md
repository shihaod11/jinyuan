## 画面、操作与美术规范

**一句话：16×16 像素地砖，内部画面 480×270，整数倍放大；键鼠操作，WASD 走路、鼠标瞄准。** 下面每项都是推荐值，标“待确认”的在任务 B3 里定。

### 画面

| 项目 | 推荐值 | 状态 |
|---|---|---|
| 地砖大小 | 16×16 像素（0x72 素材标准） | 已定 |
| 内部画面 | 480×270，一屏约 30×17 格 | 待确认：想看得更远可改 640×360 |
| 放大方式 | 整数倍放大（1080p 屏幕放大 4 倍），像素不模糊，多余部分留黑边 | 待确认 |
| 角色尺寸 | 主角约 16×28；普通怪 16×16；大怪 32×36；Boss 64 以上 | 已定（跟随 0x72） |
| 帧率 | 画面每秒 60 帧，规则每秒算 30 次 | 已定 |
| 镜头 | 跟随主角，稍微往鼠标方向偏；受重击轻微震屏（设置里可关） | 待确认 |

### 界面布局（待确认）

- 底部中间：8 格技能栏；左边生命球、右边法力球；技能栏上方是经验条
- 右上：小地图 + 区域名
- 左上：增益/减益图标
- 地上物品：名字标签按稀有度上色；黄装和传奇有光柱和音效

### 颜色规则

- **稀有度**：普通白、魔法蓝、稀有黄、传奇橙（刷子游戏通用约定）
- **元素**：火 = 橙红，冰 = 青蓝，电 = 白紫，毒/混沌 = 绿紫，物理 = 白灰。技能特效、伤害飘字、词缀文字都用同一套颜色，玩家一眼能看出“这是什么系”
- **统一色板**：以 0x72 素材的颜色为基准做一张 32 色色板；其他素材和 AI 生成的图，用之前先换成这张色板里的颜色，避免看着像拼盘

### 字体与声音

- 中文像素字体：方舟像素字体 / 缝合像素字体（开源；下载前核实协议，并记进 LICENSES.md）
- 音效：用 jsfxr 这类生成器现做 + Kenney 的免费音效（CC0）
- 音乐：第一版先用免费授权曲目，记清来源；以后可以自己做
